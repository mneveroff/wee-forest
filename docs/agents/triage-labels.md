# Triage labels

The skills use five canonical triage roles. In Linear, each role maps to a label with the same name:

- `needs-triage` → `needs-triage`: maintainer needs to evaluate
- `needs-info` → `needs-info`: waiting on the reporter
- `ready-for-agent` → `ready-for-agent`: fully specified and ready for an AFK agent
- `ready-for-human` → `ready-for-human`: requires human implementation
- `wontfix` → `wontfix`: will not be actioned

When a skill mentions a triage role, apply the corresponding Linear label while preserving unrelated labels.
